# Code of conduct

## The standard

This project adopts the [Contributor Covenant, version 2.1][covenant] in full.
It is linked rather than copied because a copy is a second thing to keep in step
with the original, and the original is maintained better than a fork of it would
be.

Read it if you have not. The short version: treat people with respect, assume
good faith, and do not make this a place somebody has to be tough to participate
in.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## One thing worth saying plainly

**Review here is blunt about work and never about people.** This repository
argues with itself constantly and in writing — a decision record that names no
cost is called marketing, a guarantee nobody has attacked is downgraded in the
registry rather than defended, and a check that has never been watched fail is
treated as no check at all. Patches get read closely and questioned.

That is a standard applied to the work, and it cuts hardest against whoever wrote
it last, which is usually the maintainer. It is not licence to be unkind to a
person, and "I was just being rigorous" is not a defence for anything in the
Covenant's list. If review here ever reads as contempt for you rather than
scrutiny of a change, that is a failure of the review and worth saying so.

## Reporting

The repository is private and has one maintainer, so the honest answer is that
there is no committee and no dedicated address yet.

* **A concern about behaviour** — open a minimal public issue saying only that
  you need a private channel and nothing more, and you will be contacted. Or use
  GitHub's own *Report abuse* flow, which does not go through the maintainer at
  all and exists for exactly the case where the maintainer is the problem.
* **A security vulnerability** — not this file. See [SECURITY.md](SECURITY.md);
  it has a private channel of its own.

Reports are read by the maintainer, kept private, and answered. When this project
has more than one person, a dedicated address and a named contact other than the
maintainer replace this section — a code of conduct whose only enforcement route
runs through one person is a weak one, and it is worth admitting that while it is
still true.
